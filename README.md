# mdrun

A CLI tool that executes code blocks from Markdown files. Makes development setup easier and keeps README maintained.

## Setup

### Install Dependencies

```bash
pnpm install
```

### Build

```bash
pnpm build
```

## Development

### Run Tests

```bash
pnpm test
```

### Type Check

```bash
pnpm typecheck
```

### Lint

```bash
pnpm lint
```

### Format

```bash
pnpm fmt:check
```
